# CLAUDE.md

This project's instructions for AI agents live in **[AGENTS.md](AGENTS.md)**.

Read it before doing anything else. The short version:

- This is an NLP research project: extract **interpersonal networks** (who worked with,
  disagreed with, taught whom) from Wikipedia into a typed, evidence-bearing graph.
- The repo is **spec-driven**. Specs live in [`docs/specs/`](docs/specs/).
  Non-trivial code starts as an accepted spec — see
  [`docs/specs/README.md`](docs/specs/README.md) for the process.
- Never contradict an accepted spec silently. Flag the conflict instead.
